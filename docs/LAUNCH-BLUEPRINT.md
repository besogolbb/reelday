## 3. The two engines, running in parallel

| | ENGINE 1 — INTENT (80% effort) | ENGINE 2 — PROOF (20% effort) |
|---|---|---|
| **Job** | Book paying events *now* | Manufacture credibility |
| **Inputs** | Groups, DMs, vendors, ₱5k ads | 1–3 free hero events |
| **Output** | ₱ bookings this month | Testimonials, footage, hero reels |
| **Feeds** | Revenue + the June target | Engine 1's ads, posts, and pitch |
| **Risk if skipped** | No revenue | High CAC, weak trust, slow scale |

> They depend on each other: Engine 2's footage is the ammo Engine 1 fires. Run a hero event in Week 2 specifically so Engine 1 has proof for Weeks 3–4.

## 4. The offer architecture ("Founding 20")

```
  HESITATION (new product)        →   ANTIDOTE
  ─────────────────────────────────────────────────────
  "Is it worth ₱2,990?"           →   Anchored 50% off → ₱1,490
  "What if guests don't use it?"  →   Money-back guarantee
  "Why now, not later?"           →   Scarcity: 20 spots + Jun 30 deadline
  "No reviews, I'm the guinea pig"→   "Founding" status + testimonial trade
```

Steering rule by event type:
- **Wedding / big milestone** → Dalisay (Founding ₱1,490) — full features + event website
- **Debut / birthday / party** → Sinag (₱1,490) — unlimited photo+video, reactions
- **Coordinator / venue / multi-event** → Hiraya pipeline (free trial now, ₱9,990/yr later)

## 5. Channel decision tree (where do I spend the next hour?)

```
Do you have a testimonial/hero clip yet?
├─ NO  → spend on ENGINE 2 + free channels:
│        • lock a hero event
│        • answer group threads (A)
│        • send 10 warm DMs (B)
│        • pitch 2 vendors (C)
│
└─ YES → add ENGINE 1 paid + scale the winner:
         • turn on ₱5k lead ad anchored on the clip (D)
         • boost the single best organic post
         • double down on whichever of A/B/C is replying most
         • kill anything with 0 replies after a fair test
```

**Money rule (₱5k):** don't spend a peso on ads until ≥1 testimonial exists. Then ~₱3k lead ad + ~₱2k boost. Reallocate weekly to the lowest cost-per-booking source.

```
 Best channel        ?     ?     →     →    │  (lock by Wk3)
```

**Leading indicators** (move first): qualified leads, demo links sent, group replies.
**Lagging indicators** (the goal): paid events, cost/booking. If leading is up but lagging is flat → the *offer/close* is the leak, not the top of funnel.

## 8. Operating system (the non-negotiables)

```
DAILY  (~60–90m)   AM: clear DMs/comments, glance ad metrics
                   Midday: 10 DMs + 2–3 group threads + 1 vendor touch
                   PM (7–9 PHT): publish 1 post, engage 20m, log leads

WEEKLY (Sun)       Update KPI sheet · kill/scale ads · check the week's GATE
                   · plan next week's content + follow-ups

GUARDRAILS         • 1 CTA per post   • proof before pricing
                   • help in groups, don't advertise   • never buy engagement
                   • reply within the hour at peak     • intent > reach, always
```
