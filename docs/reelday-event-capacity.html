Reelday — Event Capacity Guide

For the booking and ops team. Plain-language answers to "can we accept this event?" Last updated 13 May 2026, based on live production load tests.

⚡ Quick Answers (Read This First)

QuestionAnswer
How many guests can attend a single event?Up to 800 guests with smooth experience. 800–1,200 still works but wall lags 10 min during peak moments. Above 1,200 — wait for AWS quota raise.
How many guests can upload at the exact same second?1,000 guests tested with 0 failures. Every guest's upload starts within ~4 seconds.
How many guests can react with emojis at the same time?500+ at once, no problem. Tested with 2,000 reactions in 5 seconds, all landed.
How many events can run at the same time?4 events of 200 guests each is comfortable. Up to 2 events of 500 guests overlapping. Larger combinations need AWS quota raise.
Can the wall display handle a busy event?Yes. Tested with 1 host wall + 600 simultaneous uploads + reactions, all working.
Will videos appear on the wall instantly?Most yes — within ~30 seconds. During peak upload bursts (cake-cutting, bouquet toss), they appear gradually over 5–17 minutes as the transcoder processes them.
What's the limit per video upload?30 seconds long, max 100 MB per file. 4K videos auto-optimized.
Will the platform crash during a long event?No. Tested 3 minutes of continuous traffic — latency stayed flat, no memory leaks. Server can run all-day events.
What if uploads fail or get stuck?They don't get lost. Messages stay queued for 4 days. Wall just catches up later. Zero failures across all our load tests.

📋 Pre-Event Day-Of Checklist

  1. The day before: confirm the event's QR code works and the wall URL loads on the venue's actual TV/projector.
  2. 1 hour before: verify the wall page on the host's actual venue WiFi — not on hotspot. Sometimes venues block ports.
  3. 30 min before: check that the Reelday platform is responsive — open https://reelday.ph/api/health in a browser. Should load in under 1 second.
  4. For events > 500 guests: warn the host upfront that wall may lag 5–10 minutes during peak upload moments. Set expectations early.
  5. If wall ever shows a stuck "processing" video: open https://reelday.ph/api/uploads/<event-slug>?reconcile=1 once. Forces a refresh.

6 · Quick Booking Rules

Safe to book without thinking

  • 1 event up to 800 guests at any time
  • 2 events up to 400 guests each, overlapping
  • 4 events up to 200 guests each, overlapping

Book with care — warn the host that wall may lag 5–10 min during peak upload bursts

  • 1 event of 800–1,200 guests
  • 2 events of 500–800 guests overlapping
  • 5 events of 200–400 guests overlapping

Do not book until AWS Lambda quota is raised

  • Any single event > 1,200 guests
  • Any combination producing > 700 simultaneous active guests
  • Any combination producing > 300 burst uploads in a 5-minute window

7 · Operational Reminders

Always direct R2 uploadGuest browsers PUT directly to R2 via pre-signed URL. The backend never proxies the file. Confirms instant "✓ Uploaded" even during heavy bursts.
SQS absorbs all upload burstsEven at 1,000 simultaneous uploads, every one queues successfully. Wall just lags — nothing is lost. Messages persist for 4 days.
Lambda is the throughput bottleneckCurrently capped at 35 videos/min total across the platform. Once AWS approves the concurrency raise, this jumps to ~700 videos/min, unlocking events of 3,000+ guests.
If wall ever shows a stuck "processing" videoHit https://reelday.ph/api/uploads/<slug>?reconcile=1 once. Forces a self-heal for missed transcode webhooks.

8 · Pre-Event Checklist (recommended)

  1. Confirm SQS queue depth is 0 (AWS Console → SQS → reelday-transcode.fifo)
  2. Confirm Lambda timeout is 180 s and reserved concurrency is set
  3. Run wall poll baseline: curl -w "%{time_total}s\n" https://reelday.ph/api/uploads/<slug> — expect < 1 s
  4. For events > 500 guests: run node scripts/stress-wall.mjs <slug> 300 1500 — expect 0 failures
  5. Verify backend Easypanel container is running, not in restart loop
  6. Verify host's wall display loads cleanly with the actual venue WiFi (not mobile hotspot)
